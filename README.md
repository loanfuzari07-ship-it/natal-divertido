# Deu Ruim no Natal!

Página estática pronta para GitHub e Vercel. Os arquivos index.html, vercel.json e a pasta assets devem ficar na raiz do repositório.

## Publicar

1. Extraia este ZIP e envie todo o conteúdo para um repositório no GitHub. Não envie apenas o ZIP.
2. Na Vercel, escolha Add New > Project e importe o repositório.
3. Framework Preset: Other. Root Directory: raiz do repositório.
4. Deixe Build Command vazio e Output Directory no padrão (raiz). Não requer instalação, variáveis de ambiente ou compilação.
5. Clique em Deploy.
